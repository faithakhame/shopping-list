# Pantry Party 🛒

A lightweight stock tracker and shopping list web application for your kitchen and household. Track what you have, monitor items that are running low, and manage your shopping list.

## Features

- 🧺 **Stock Tracker**: Keep an inventory of groceries, household supplies, and pantry items with category filtering and quantity tracking.
- ⚠️ **Low Stock Alerts**: Automatically highlights items running low so you never run out of essentials.
- 🛒 **Shopping List**: Add items to buy and check them off as you shop.
- 💰 **Value Estimation**: Track estimated inventory value and spending.
- 💻 **Pure Vanilla Web**: Built with HTML5, CSS3, and JavaScript — no build steps or dependencies required.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/faithakhame/shopping-list.git
   ```
2. Open `index.html` in your web browser.
